# Save Any Pets: how to run the site

This is a plain language guide to the admin panel. Nothing here needs any technical
knowledge. If something does not match what you see on screen, ask your developer,
the site may have changed since this was written.

Everywhere below, "the admin panel" means going to your website address followed
by `/admin`, for example `https://www.yoursite.org/admin`.

## Logging in

1. Go to `/admin`.
2. Enter the email and password your developer set up for you.
3. Select "Sign in".
4. You will land on the Dashboard, which shows how many pets are available, how
   many applications are open, and today's meet-and-greets.
5. The menu on the left (or the menu icon on your phone) gets you to Pets,
   Applications, Meet-and-greets, Stories, Guides, People and Settings.
6. To leave the admin panel and see the public site, select "View website" at the
   bottom of the menu.
7. When you are done, select "Sign out" at the bottom of the menu.
8. If you forget your password, ask your developer to reset it, there is no
   self-service reset link yet.

## Adding a pet with photos

1. In the menu, select "Pets".
2. Select "Add a pet".
3. Fill in the name, species, sex, size and breed.
4. Fill in age, weight or length, and a short story about the pet in your own words.
5. Tick the health checks that apply (vaccinated, spayed or neutered, vet checked)
   and add any health notes.
6. Set the adoption fee. This is the fee shown to the public, so make sure it is
   right before saving.
7. Set the status to "Available" so the pet shows up on the site (use "Draft" if
   you are not ready to publish yet).
8. Save the pet, then scroll to the Photos section.
9. Add a short alt text describing the photo (for example "Rex sitting in the
   yard"), then select "Choose photo" and pick the image. Repeat for each photo.
10. Use the star button to set the main photo, and the up and down arrows to put
    them in the order you want.

## Reviewing and approving an application

1. In the menu, select "Applications".
2. New applications appear under the "New" tab. Select one to open it.
3. Read through the applicant's answers, grouped the same way as the form they
   filled in (about them, their home, their experience, and their chosen
   meet-and-greet time).
4. Add any private staff notes in the notes box, these are never shown to the
   applicant and save automatically as you type.
5. If you want to note that you are looking into it, select "Mark in review".
6. If the application looks good, select "Approve". This sends the applicant an
   email and marks the pet as pending.
7. If it is not a good fit, select "Decline". This also sends the applicant a
   polite email. You will be asked to confirm before this happens.
8. Once the adopter has paid the fee in person and taken the pet home, come back
   to this application and select "Mark completed". This sends a welcome email
   and marks the pet as adopted.
9. Remember: no payment is ever taken before the meet-and-greet, and the pet
   should only be marked adopted once they have actually gone home.

## Creating meet-and-greet slots

1. In the menu, select "Meet-and-greets".
2. You will see a list of upcoming slots and who has booked each one.
3. To close a slot you no longer want people booking (for example if you are
   closed that day), use the open or close toggle next to it.
4. To add new slots, scroll to the "Create slots" form.
5. Choose a start date and an end date, this creates a slot on every day in that
   range.
6. Set how many people can book each time (capacity), usually 1.
7. Type the times you want to offer each day, in 24 hour format (for example
   `10:00, 13:00, 15:30`).
8. Select "Create slots". You will see a message confirming how many were made.
9. These times will now appear as options on the adoption application form.

## Publishing a success story

1. In the menu, select "Stories".
2. Select "New story" (or an existing story to edit it).
3. Only add a story once the adopter has agreed you can share it. Tick "The
   adopter has given consent to publish this story", this is required before a
   story can go live.
4. Add a title, the adopter's first name, and the story itself. You can preview
   how it will look as you type.
5. Add a photo if you have one, with the adopter's permission.
6. Tick "Published" when you are ready for it to appear on `/success-stories`.
   Leave it unticked to save a draft first.
7. Save the story.
8. Never write a story that did not really happen, real adoptions only.

## Publishing a care guide

1. In the menu, select "Guides".
2. Select "New guide" (or an existing guide to edit it).
3. Add a title, pick the species it is for (or leave it general), and write a
   short summary.
4. Write the guide body. You can use simple formatting like headings and lists,
   and a preview shows how it will look.
5. Add a cover photo if you have one.
6. Tick "Published" when you are ready for it to appear on `/care-guides`. Leave
   it unticked to keep working on it first.
7. Save the guide.
8. Three starter guides (dog, cat and bearded dragon) already exist. Open each
   one and replace the "Reviewed by: [VET OR STAFF NAME]" line at the top with a
   real name before launch.

## Updating site settings

1. In the menu, select "Settings" (only visible if your account is an admin, not
   regular staff).
2. Under "Shelter details", update your address, phone, WhatsApp number, email
   and registration number. These appear on the Contact page and in the site
   footer.
3. Under "Adoption fees", set a default fee for dogs, cats and bearded dragons.
   This is shown on the "How it works" page. You can still set a different fee
   per pet when adding or editing that pet.
4. Under "Opening hours", fill in the hours for each day you are open. Leave a
   day blank if you are closed or have not decided yet.
5. Under "Donations", add your bank transfer details (bank name, account name,
   account number, branch code). This site never takes donations or payments
   online, bank transfer only.
6. Select "Save settings" at the bottom. You will see "Saved" confirm it worked.
7. Changes here show up on the public site within a few seconds.
